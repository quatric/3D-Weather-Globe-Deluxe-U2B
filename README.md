# 3D Weather Globe Deluxe 2.0.7-U2B

Version-patched packaging for 3D Weather Globe Deluxe. This repository contains only the patched `Info.plist` (version `2.0.7-U2B`), DMG layout settings and a build script. It does not contain the application itself; supply your own copy of the app.

You can download the compiled DMG on MacSerialJunkie or MacBB.

    ./build.sh "/path/to/3D Weather Globe Deluxe Edition.app"
